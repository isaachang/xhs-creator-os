# 独立生理结构审查边界

封面和知识卡生成后都必须加载。它是独立于图片生成上下文的审查协议，不是 Baoyu 的自检提示词。

## 唯一审查目标

只检查画面中可见角色的生理结构是否出现明确错误：

- 单个角色是否多出或缺少耳朵、眼睛、鼻子、嘴巴、腿、爪子或尾巴；
- 肢体是否从身体合理连接，是否出现明显粘连、断裂、重复或残影；
- 同一个角色内部是否出现两个头、多个身体或其他明显不可能的结构。

## 多实例例外

同一只动漫 IP 在一张图中出现两个或多个独立插画实例，不算生理结构错误。以下情况默认允许通过：

- 两个不同姿势或表情的同款角色；
- 分镜、对比、前后状态或多个信息区域中的同款角色；
- 每个角色实例边界清楚，且每个实例自身的耳朵、眼睛、四肢和尾巴结构正常。

审查 Agent 不得仅因为“画面里有两个狗狗”而判定 FAIL。只有当两个形象发生身体粘连或重叠，导致某一个角色实例出现多余部位或不可解释的生理结构时，才需要报告问题。

## 明确不审查

以下内容全部不属于本审查：

- 文字、错别字、文字可读性；
- 排版、构图、留白、元素遮挡；
- 场景、道具、数量和内容是否符合正文；
- IP 是否还是同一只狗、品牌一致性或风格一致性；
- 是否写实、是否好看、是否高级；
- 文案事实、政策内容和账号定位。

## 结论和返工

- 返回固定结论：`PASS`、`PASS_WITH_NOTE` 或 `FAIL`。
- `PASS_WITH_NOTE` 只用于轻微或不影响使用的结构瑕疵，不阻断流程，不触发返工。
- 只有明确的多余/缺失身体部位、明显断裂粘连或不可解释的生理结构才返回 `FAIL`。
- 不要因为姿势夸张、毛发遮挡、画风不对称或多个独立角色实例而 FAIL。
- 对同一张图最多审查/返工 3 次；第 3 次仍 FAIL 时返回最终结构问题。
- 不直接修改已经生成的位图。
