# 小红书生图流程

本文件只在用户明确提出“生图”“图片卡片”“小红书配图”或“审图”时加载。

## 执行清单

1. 调用独立的 `baoyu-xhs-images` Skill，使用项目级 `.baoyu-skills/baoyu-xhs-images/EXTEND.md` 偏好。
2. 每张图片先保存完整 Prompt，再调用图片生成后端。
3. 封面先生成并检查，通过后再生成后续卡片；后续卡片使用封面作为系列锚点。
4. 如果主题属于狗狗账号 IP，读取 `ip-routing.md`。
5. 如果用户明确要求审图，读取 `anatomy-review-agent.md`，每张候选图交给独立审图上下文。
6. 失败只重新生成对应卡片，保留失败样本和修复 Prompt；禁止直接涂改位图。

## 边界

- 生图不会被调研、仿写或 Compare 自动触发。
- 狗狗 IP 素材只在相关主题和生图请求同时成立时加载。
- 独立审图只判断图片结构和文字可读性，不判断账号定位或文案质量。
