# Rewrite 输出格式

## 元信息

仿写结果先展示原笔记元信息，结构与 Research 样本保持一致：

```text
仿写任务
数据源：本次实际数据源（Apify → SocialDataX / 本机 MediaCrawler → Rednote 或小红书）
原笔记标题：[提供方返回的原始标题](提供方返回的原始 note_url)
作者信息：[作者名称](作者主页 URL；没有时只显示作者名称)
发布日期：日期；缺失时写“未知”
笔记类型：图文 / 视频；缺失时写“未知”
原笔记数据：赞 X｜藏 X｜评 X｜转 X
```

无论来源是 SocialDataX 还是 MediaCrawler，原始标题都必须直接链接到本次提供方返回的 `url`；作者主页 URL 没有值时不补造链接。标题与作者必须在聊天窗口以 Markdown 链接展示，不能只输出纯文字。元信息不计入发布正文字数。

元信息在原笔记数据后追加：

```text
账号匹配：匹配 / 不匹配 / 不确定
本次处理：账号定位仿写 / 原主题仿写
```

用户只要求“仿写”且账号不匹配时，固定显示“账号匹配：不匹配｜本次处理：原主题仿写”。用户明确要求账号适配但当前没有账号主题素材时，只输出来源元信息与简短澄清，不输出标题、钩子、正文或 CTA。
