# 前期调研功能清单

本文件只服务于“通过 Apify → SocialDataX 搜索公开小红书笔记”的调研路径。

## 默认参数

- 数据源：`Apify → SocialDataX`
- 默认结果：15 条；用户明确测试或要求更多时，按要求抓取，当前测试可返回 20 条。
- 默认排序：综合。
- 默认笔记类型：全部。
- 默认发布时间：不限。
- 关键词：使用用户提供的关键词；用户没有提供时，根据账号定位生成一个最直接的搜索词，不扩展成多组复杂研究任务。

## 执行清单

1. 读取 `profile/account.yaml`，只用于理解账号方向，不在回复里复述整份定位。
2. 按 `references/data-sources.md` 的规则确认 API 配置、套餐状态和缓存。
3. 运行 `python3 scripts/xhs_api.py status`，确认 Apify 配置和套餐状态；API Key 只从环境、`.env.local` 或 macOS Keychain 读取，绝不输出。
4. 调用 SocialDataX `search_notes`。
5. 将结果保存到运行目录并导入 `scripts/store.py`。
6. 使用 `scripts/trend_report.py` 生成第一段结果。

## 调研结果格式

```text
调研方向
数据源：Apify → SocialDataX
关键词：用户关键词
排序：综合
笔记类型：全部
发布时间：不限
抓取结果：15 条 / 实际返回数量

样本列表

[笔记原文标题](SocialDataX 返回的原始 URL)
作者账户：[作者名称](作者主页 URL，如果有)
赞 X｜藏 X｜评 X｜转 X

……完整列出全部样本……
```

## 输出规则

- 必须列出全部抓取样本，不因为相关性弱而删除。
- 标题必须使用 SocialDataX 返回的原始笔记 URL，不能改成 404 链接、短链或自行拼接的链接。
- 每条笔记都要显示作者名称；有作者主页 URL 时一并加链接。
- 显示赞、藏、评、转；缺失值写“未知”，不能写成 0。
- 相关性、噪声和待确认内容只用 `⚠️` 提示，不筛除。
- 不自动跳转到 Booking、官网或其他公开网页做第二轮核验，除非用户明确要求。
- 不把样本直接总结成“平台趋势”或“候选方向”。先完整返回样本，再由用户选择下一步。

## 样本结束后的下一步选项

1. 提取高频主题、地点、规则和用户痛点。
2. 对比正面体验、负面体验和争议点。
3. 从样本中提炼 3–5 个选题方向。
4. 指定一条笔记，读取正文并做结构拆解。
5. 指定一条笔记，进入仿写流程。
