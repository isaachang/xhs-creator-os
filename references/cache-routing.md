# 缓存优先与兼容性判断

适用于所有本机 MediaCrawler 数据调用：关键词调研、单篇详情、作者采集和 Compare。目标是避免不必要的登录与平台请求，但不能让“看起来相似”的旧数据替代本轮需求。

## 固定顺序

1. 先解析用户意图，得到任务类型、主题 / 对象、地区、限制条件、内容类型、排序、发布时间、数量、是否要求最新 / 刷新。
2. 在不启动 Media 浏览器、不检查登录态前，先检查本地正式 Research、统一详情缓存和作者采集结果。
3. 对候选缓存做兼容性判断，结果只能是“可直接复用 / 仅供参考 / 不兼容”。
4. 只有“可直接复用”才跳过 Media 登录和新抓取；“仅供参考”不得直接返回为本轮正式结果，需在缓存基础上走 Media 补足；“不兼容”忽略缓存，正常进入 Media。

关键词调研与作者结果默认只复用 7 天内的正式 Media 结果。用户明确说“最新”“重新调研”“刷新”，或命令带 `--refresh` 时，跳过关键词 / 作者 Research 缓存并重新抓取；单篇详情是否刷新仍以用户是否明确要求刷新为准。

## 兼容性门槛

### 单篇详情 / 仿写

只接受相同 `note_id` 或标准化后等价的笔记 URL。命中时可直接复用详情；这不会因为标题相似而误命中。

### 作者主页

必须是同一 `author_id` 或同一标准化主页链接；同时满足本轮排序、Top-N 数量和所需详情覆盖。缓存仅有 Top 5 时，不能直接替代“收藏最高 Top 15”。

### 关键词调研

自动复用要求以下必填条件全部兼容：

- 任务类型一致（关键词调研不能用作者采集或单篇详情替代）；
- 地区 / 地点不冲突；
- 核心对象与主题一致（如“餐厅”不能被“商场”替代）；
- 用户明确的排除条件、内容类型、排序、发布时间条件兼容；
- 正式样本量和详情覆盖满足本轮需求；
- 缓存仍符合本轮时效要求。

“广州宠物友好餐厅”与“广州天河宠物友好餐厅”属于部分匹配，不能自动复用；“广州天河宠物友好商场”与“广州天河宠物友好餐厅”属于不兼容。

## 结果呈现

- 缓存复用时，在任务头部标注“复用本地缓存”和原抓取日期；输出结构、作者、原始链接、互动快照及后续选项不变。
- 部分匹配缓存只能作为本轮筛选 / 补搜的辅助上下文，不向用户伪装为正式样本。
- 缓存不足时，保留已复用的详情，不重复读取同一笔记；只让 Media 抓取缺口。
- 无法判断兼容性时按“仅供参考”处理，不能为了省请求自动命中。
