# 共享账号定位规则

- 只读取 `profile/account.yaml` 理解账号定位、受众、内容支柱、语气和事实边界。
- 没有关键词时，Research 只根据账号定位生成一个最直接的搜索词，不扩展成多组复杂研究任务。
- 不在普通调研或仿写结果中复述整份账号定位。用户只给笔记链接并说“仿写”时，账号定位不改变原笔记主题。
- Rewrite 仅在原笔记核心主题、目标受众或使用场景明确落入账号内容支柱时，才可以按账号定位调整表达；泛泛的词面重合不算匹配。
- 原笔记与账号不匹配时，默认按原主题仿写，并在元信息中说明“账号匹配：不匹配｜本次处理：原主题仿写”。只有用户明确要求“按我的账号改写”时，才尝试跨主题适配。
- 跨主题适配不能把原笔记的结构当成新主题的事实素材。原文未提供新主题的经历、数据、案例或结论时，先用一句简短澄清说明缺少素材，请用户提供目标主题/素材或要求先做调研；此时不生成发布正文。
- 生图请求可以使用账号定位选择视觉语言和 IP 素材，但不改变用户已经确认的标题、钩子或正文事实。
