# 共享可发布正文格式

本文件被 Rewrite、Compare 和任何会生成小红书发布正文的路径共享，包括根据调研写新稿或优化用户初稿。

## 格式

- 发布正文必须放进一个 `text` 纯文本代码框。
- 代码框内不得使用 `#`、`##`、Markdown 项目符号、加粗符号或其他 Markdown 排版。
- 代码框外可以使用 Markdown 展示来源、链接、作者和说明。

## 可发布内容包

只要本次结果包含可直接发布的标题和正文，必须完整输出以下内容，不能只给一段正文：

1. 有来源笔记或调研样本时，先展示实际来源信息：原笔记标题超链接、作者账户链接（实际字段存在时）、发布日期、笔记类型和赞/藏/评/转快照。多对象 Compare 展示完整来源样本；用户只提供自己的初稿而没有来源时，不伪造来源信息。
2. 标题备选 5 个、开头钩子备选 5 个，以及推荐组合。
3. 仅一个 `text` 纯文本代码框，内含最终标题、正文和标签，供用户一键复制。
4. CTA 备选 5 个。

Rewrite 额外保留默认/轻度/深度仿写说明；Compare 不输出这些仿写模式。正文不得在代码框外直接渲染成普通段落。

## 字数

- 标题不超过 20 个字符。
- 标题、正文和标签合计不超过 1000 个字符。
- 统计时忽略换行，但空格、标点、数字、英文和 emoji 都计入。
- 元信息、来源链接、作者信息、互动数据、标题备选、钩子备选、CTA 备选和核验说明不计入发布正文限制。

## 超限压缩顺序

1. 保留核心事实和结论。
2. 删除重复信息。
3. 压缩形容词和口头填充。
4. 合并相邻句子。
5. 最后再压缩 CTA 和标签。

输出前使用 `scripts/validate_copy.py` 检查，不能直接超限返回。
